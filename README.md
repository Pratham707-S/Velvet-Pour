# 🍸 Velvet Pour

A stunning cocktail bar website built with **React**, **GSAP**, and **Vite**.

## Features
- Smooth GSAP scroll animations
- Beautiful cocktail showcase
- Responsive design
- Custom typography & premium aesthetic

## Tech Stack
- React 19
- GSAP (GreenSock Animation Platform)
- Vite
- Vanilla CSS

## Getting Started
```bash
npm install
npm run dev
```
